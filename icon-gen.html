🎨 ArthaNote Icon Generator

512 × 512 (Play Store)
192 × 192 (Home Screen)

Download both files → replace existing icon-512.png and icon-192.png in the Kannakupilai repo folder → commit & push.

📋 After downloading:

  1. Save both files into your Kannakupilai/ folder (overwrite existing icons)
  2. Run: git add icon-512.png icon-192.png
  3. Run: git commit -m "New app icon — ArthaNote Shop Ledger"
  4. Run: git push
  5. Go to pwabuilder.com → enter https://arthanote.com
  6. Build → Android → package name com.arthanote.app
  7. Download .aab file → upload to Google Play Console
