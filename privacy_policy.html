2. About ArthaNote

Summary: ArthaNote is a digital ledger app for small businesses. It replaces paper account books with a secure, cloud-synced mobile app. Available on Android, supporting English, Tamil, and Hindi.

ArthaNote is a comprehensive digital business management and accounting application developed specifically for small retailers, traders, shop owners, and micro-enterprises. The name "Artha" (अर्थ) means "wealth" or "money" in Sanskrit, reflecting the app's purpose of helping users manage their finances effectively.

2.1 Core Purpose

ArthaNote digitizes the traditional paper-based "khata" (account book) used by millions of small retailers across South Asia and beyond. It provides a secure, cloud-backed, mobile-first solution to record and manage:

  • Daily sales and revenue entries
  • Expense tracking (rent, utilities, purchases, staff costs)
  • Customer credit ledgers (udhaar/credit tracking)
  • Supplier payment records and outstanding bills
  • Staff attendance using QR code scanning
  • Chit fund group management (a popular savings mechanism in South Asia)
  • Multi-shop management for businesses with more than one outlet
  • Management Information System (MIS) reports across 15 categories

2.2 Platform and Availability

ArthaNote is available as an Android application distributed through the Google Play Store. The application also functions as a Progressive Web Application (PWA) accessible via web browsers. The app supports three languages: English, Tamil (தமிழ்), and Hindi (हिंदी), making it accessible to users across India and the South Asian diaspora worldwide.

2.3 Subscription Model

ArthaNote offers a free tier with basic features (one shop, standard ledger functions) and a Pro subscription at ₹199 per month, processed through Google Play Billing. Pro features include unlimited shops, OCR receipt scanning, full MIS reports, and priority support.

2.4 Developer Information

ArthaNote is developed and maintained by Selva Vishnu M, an independent software developer based in Tamil Nadu, India. The developer is the sole data controller for personal data processed through ArthaNote.

11. Security Measures

Summary: Your data is encrypted in transit (HTTPS/TLS) and at rest (Google Firebase encryption). Access is controlled by Firebase Security Rules so only you can read your data. We follow security best practices for a mobile application.

11.1 Technical Security Measures

We implement the following technical security measures to protect your personal data:

11.1.1 Encryption in Transit

  • All data transmitted between ArthaNote and Firebase servers is encrypted using TLS (Transport Layer Security) version 1.2 or higher;
  • HTTPS is enforced for all API calls and data synchronization operations;
  • Firebase SDK connections use Google's SSL/TLS infrastructure with certificate pinning at the SDK level.

11.1.2 Encryption at Rest

  • All data stored in Cloud Firestore is encrypted at rest by Google using AES-256 encryption by default;
  • Firebase Authentication credentials are hashed using bcrypt (for email/password accounts) — your password is never stored in plain text;
  • Google's encryption key management for Firestore includes regular key rotation and hardware security module (HSM) protection.

11.1.3 Firebase Security Rules

Our Firestore database is protected by security rules that enforce:

  • Authentication requirement: All read and write operations to your business data require a valid Firebase Authentication token — unauthenticated requests are rejected;
  • User isolation: Each user's data is stored under their unique UID and is only accessible when authenticated as that user;
  • Attendance data: Attendance records allow public write (for QR scan by staff without login) but all other data is authentication-protected.

11.1.4 Local Device Security

  • Data cached locally on your device (for offline functionality) is stored in the device's app-sandboxed storage, inaccessible to other apps;
  • API keys you enter (Gemini, Claude) are stored in device-local storage and are never transmitted to ArthaNote servers;
  • Firebase Authentication tokens are stored in secure token storage on your device.

11.2 Organizational Security Measures

  • Access control: Access to Firebase Console and production data is restricted to the developer (Selva Vishnu M) with strong authentication;
  • Principle of least privilege: Only the minimum data required for each operation is accessed;
  • Incident response: In the event of a data breach, we will notify affected users within 72 hours of becoming aware, as required by GDPR and applicable laws;
  • Regular review: Security rules and access controls are reviewed regularly as part of app maintenance;
